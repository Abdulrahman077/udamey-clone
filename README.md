# 🎓 Udemy Clone

A **static Udemy website clone** built using **HTML and CSS**.

This project was created as a frontend practice project to improve my understanding of **semantic HTML, CSS Flexbox, CSS Grid, and responsive web design**.

# 🚀 Live Demo

[👉 View Live Demo](https://abdulrahman077.github.io/udemy-clone/)

## 📌 About The Project

This project replicates the basic layout and visual structure of the Udemy website using only HTML and CSS.

The goal of this project was to practice building a real-world website layout from scratch without using frameworks or JavaScript.

## ✨ Features

* Responsive navigation bar
* Search bar
* Category/menu navigation
* Hero section
* Recommended courses section
* Recommended topics section
* Popular courses section
* Course cards with ratings and pricing
* Responsive footer
* Mobile-friendly layout
* Responsive design using CSS media queries

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Box model

## 📚 What I Learned

Through this project, I practiced:

* Creating semantic HTML layouts
* Structuring a real-world website
* Using Flexbox for alignment and navigation
* Creating responsive designs
* Using media queries for different screen sizes
* Styling cards, buttons, forms, and navigation elements
* Organizing HTML and CSS files properly
